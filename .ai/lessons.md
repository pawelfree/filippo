# Lessons learned

Read this index before working on related areas. Add concise, evidence-based lessons here after a bug fix or other reusable finding. Put longer explanations in `lessons/YYYY-MM-DD-slug.md` and link them from the entry.

- Różne tryby nauki korzystające z jednego FSRS powinny współdzielić wybór kolejki i historię prób. W cloze osobna selekcja oraz brak `StudyAttempt` ukrywały utrwalenia przed ekranem „Nauka”; zobacz [integrację FSRS](runs/2026-11-03-cloze-fsrs-queue.md).
- Przy serii ćwiczeń zachowuj poprzednie rekordy i trwały przydział do sesji. Utrwalenie lokalne używa tego samego rekordu, kolejna sesja niewykorzystanego rekordu, a wyczerpanie puli uruchamia nowy zestaw; zobacz [integrację cloze](runs/2026-11-03-cloze-fsrs-queue.md).

- Akcja ręcznego odświeżenia powinna wyraźnie wyglądać na dostępną i sygnalizować trwający odczyt na samym przycisku, bez zbędnego potwierdzenia sukcesu. Gdy automatyczny odczyt już trwa, zapamiętaj ręczne żądanie zamiast cicho je pomijać; zobacz [widok stanu cloze](runs/2026-11-03-cloze-refresh-control.md).

- Postęp zakończonego lub przerwanego generowania zapisuj w rekordzie zlecenia podczas pracy. Wyliczanie go z obecnej puli ćwiczeń zmieniało historię starego zlecenia po nowym generowaniu; starsze rekordy bez licznika oznacz jako nieznane. Zobacz [poprawkę cloze](runs/2026-11-03-cloze-progress-and-answer-feedback.md).
- Po zapisaniu oceny zachowaj informację zwrotną do jawnego przejścia dalej. Odpowiedź API może już wskazywać kolejne ćwiczenie, ale natychmiastowe renderowanie go ukrywa rozwiązanie poprzedniego. Zobacz [poprawkę cloze](runs/2026-11-03-cloze-progress-and-answer-feedback.md).

- Historia zleceń generowania służy do obserwacji stanu i błędów. Nie dodawaj w niej akcji otwierania sesji nauki, jeśli użytkownik oczekuje tylko informacji o generowaniu; zobacz [korektę widoku cloze](runs/2026-11-03-cloze-generation-status.md).

- Worker AI musi sprawdzić istnienie i stan zadania po oczekiwaniu na model, a zapis wyniku i postępu wykonać atomowo. Reset może w tym czasie usunąć sesję; zwykłe `update()` po generowaniu spowodowało `P2025` i zapis osieroconych ćwiczeń. Zobacz [naprawę workera cloze](runs/2026-11-03-cloze-worker-session-deletion.md).
- Gdy serwer korzysta ze skilla zapisanego w repozytorium, odczytuj schematy z jego istniejącego `references/`. Stara ścieżka do nieobecnego `generation_rules/` powodowała błąd ładowania modułu; poprawiono ją przy [nauce cloze](runs/2026-11-03-cloze-study-implementation.md).
- Sesja ćwiczeń powinna utrwalać listę wybranych znaczeń przed generowaniem. Po niepowodzeniu jednej pozycji pokaż powód i przejdź przez pozostałe z tej samej listy; liczba wygenerowanych ćwiczeń nie wyznacza końca sesji. Dotyczy [nauki cloze](runs/2026-11-03-cloze-study-implementation.md).
- Każde ćwiczenie leksykalne pokazuje przed odpowiedzią pełne polskie zdanie odpowiadające całemu włoskiemu zdaniu po uzupełnieniu luk. Sama etykieta znaczenia nie daje uczniowi pełnego sensu zdania; błąd rozpoznano po [nieudanej próbie ze wskazówką](runs/2026-11-03-exercise-meaning-cue.md) i poprawiono w [kontrakcie tłumaczenia](runs/2026-11-03-exercise-polish-sentence.md).
- Gdy liczba generowanych ćwiczeń na znaczenie się zmienia, zaktualizuj zarówno reguły przydziału i kontroli całej serii, jak i pola schematu pojedynczego ćwiczenia. Schemat pojedynczego rekordu nie sprawdza liczności zestawu; tę kontrolę musi wykonać generator. Dotyczy [kontraktu generowania](runs/2026-11-03-exercise-generation-contract.md).
- Przy generowaniu AI licz próby osobno dla każdego miejsca na wynik; ponowny wybór celu i końcowa kontrola nie mogą odnawiać limitu. Po wyczerpaniu prób lub kandydatów zwróć poprawne wyniki i jawne niepowodzenia, aby seria kończyła się przewidywalnie. Dotyczy [ograniczenia prób](runs/2026-11-03-bounded-exercise-generation.md).
- Gdy wynik jednego skilla zasila inny, przekazuj projekcję danych potrzebnych drugiemu zadaniu, zachowując identyfikator zapisanego rekordu. Pełny `LexicalSense` zawiera informacje źródłowe i metadane, których generator ćwiczeń nie używa; zobacz [kontrakt wejścia](runs/2026-11-03-lexical-sense-generation-input.md).
- Endpoint pobierający wybrane `LexicalSense` po ID powinien zwracać tylko ich projekcje. Profil i taksonomia mają osobne odczyty; dołączenie ich do odpowiedzi rozszerzyło kontrakt poza żądany zakres. Dotyczy [korekty endpointu](runs/2026-11-03-exercise-input-lexical-only.md).

- Symulację przyszłych powtórek FSRS licz na kopiach pełnych kart z tą samą aktywną konfiguracją co rzeczywiste oceny. Ogranicz liczbę zdarzeń i czas obliczenia oraz pokazuj rozkład ocen i założenia zastępcze; inaczej wynik może wyglądać jak zapisany harmonogram lub utracić rozdział między formalną oceną a lokalnym utrwaleniem. Sprawdzono w [teście symulacji](../tests/study-simulation.test.ts).

- Statystyki FSRS odczytuj z migawki kart i ocen: pierwsza formalna ocena znaczenia w dniu Warszawy wyznacza skuteczność, a lokalne utrwalenia licz osobno. Prawdopodobieństwo przypomnienia licz z pełnej karty i przypisanej jej rewizji konfiguracji; błąd tej części nie powinien ukrywać historii. Sprawdzono w [teście statystyk](../tests/study-statistics.test.ts).

- Oczekujące utrwalenie twórz po formalnej ocenie `Again`, ale nie po `Again` w samym utrwaleniu. W przeciwnym razie błędne odpowiedzi tworzą niekończącą się lokalną kolejkę i blokują nowe znaczenia. Dotyczy [ograniczenia utrwaleń](runs/2026-10-26-limit-study-reinforcement.md).

- W kolejce nauki rozróżniaj utrwalenie po należnej powtórce od utrwalenia po pierwszym pokazaniu nowego znaczenia. Wspólny priorytet dla obu sprawiał, że błędnie ocenione nowe znaczenie wracało natychmiast przed pozostałymi nowymi. Dotyczy [kolejności nauki](runs/2026-10-26-study-reinforcement-order.md).

- Reset postępu FSRS musi w jednej transakcji usunąć próby sesji przed dziennikiem FSRS i kartami, a następnie unieważnić tokeny prezentacji z innych kart przeglądarki. Same puste tabele pozwoliłyby starej ocenie ponownie rozpocząć naukę. Dotyczy [resetu nauki](runs/2026-10-26-reset-study-progress.md).

- Schemat zapisu propozycji LexicalSense musi akceptować rekordy dopuszczone przez format odpowiedzi generowania; inaczej można utrwalić propozycję, której nie da się zapisać. Błędy zapisu pokazuj przy konkretnej propozycji. Dotyczy [naprawy zapisu](runs/2026-10-26-generation-proposal-save-empty-examples.md).

- Przy zmianie modelu FSRS zachowuj pełną kartę i dziennik wraz z rewizją konfiguracji; pola zbiorcze nie wystarczają do wiernego odtworzenia stanu. Odrzuć niepełny stary rekord zamiast nadpisać go nową kartą. Dotyczy [integracji FSRS](runs/2026-10-26-fsrs-integration-implementation.md).

- Przy ocenie znaczenia zapisuj zdarzenie sesji i ocenę FSRS w jednej transakcji, a ponowienie żądania rozpoznawaj po trwałym `eventId` wraz z danymi oceny i tokenem prezentacji. Dzięki temu utrata odpowiedzi HTTP, równoległa karta i błąd zapisu nie tworzą podwójnej ani częściowej oceny. Dotyczy [ekranu Nauka](runs/2026-10-26-study-screen-implementation.md).

- Dla długiego zadania AI zwracaj `202` po zapisaniu zadania, a wynik i decyzje użytkownika utrwalaj w bazie; pamięciowy draft wymusza utrzymywanie otwartej karty i ginie po restarcie. Zapis znaczenia oraz usunięcie oczekującej propozycji wykonuj w jednej transakcji. Dotyczy generowania LexicalSense; zobacz [run](runs/2026-10-26-finish-asynchronous-lexical-sense-generation.md).

- Keep CSS for a navigation component shared by multiple pages in an asset loaded by every page. The LexicalSense page rendered browser-default links because `.page-nav` lived only in `profile.css`; moving the rules to shared `styles.css` restored styling across all three views. Applies to shared page chrome; see the [fix run](runs/2026-10-25-lexical-navigation-style-fix.md).
- Dodając pozycję do wspólnej nawigacji, sprawdź szerokość 400 px: nagłówek o stałej wysokości może uciąć ostatni link. Pozwól nagłówkowi przejść do dwóch wierszy i sprawdź nowy oraz istniejący ekran. Dotyczy [ekranu Nauka](runs/2026-10-26-study-screen-implementation.md).
- W tytułach stron Filippo pierwsze słowo korzysta z podstawowego, pogrubionego `h1`, a kursywę `em` stosuje się do drugiej części. Objęcie całego tytułu `em` zmienia jego wygląd względem pozostałych ekranów. Dotyczy [poprawki tytułu Nauki](runs/2026-10-26-study-title-style-fix.md).
- Preserve and classify safe upstream API error codes at the server boundary. Returning only an HTTP status made OpenAI 429 failures indistinguishable; mapping documented codes to action-oriented messages lets the LexicalSense interface explain whether credits, spend limits, or request pace caused the failure. Applies to external API integrations; see the [implementation run](runs/2026-10-25-openai-limit-error-feedback.md).
- Do not leave a transport-error catch empty around an external API call. Log a concise, labeled error without credentials so the server operator can distinguish DNS, timeout, TLS, and connection failures from API responses; see the [connection log run](runs/2026-10-25-openai-connection-error-log.md).
- When a CSS class sets `display`, add an explicit `[hidden] { display: none }` rule for views initially hidden by HTML. The taxonomy browser's grid rule would otherwise override the user-agent treatment of `hidden` before data loaded. Applies to browser interfaces with conditional sections.
- When validating JSON Schema with Ajv, install and register `ajv-formats` for schemas that rely on `date-time` or `uri`; Ajv does not enforce those format keywords by itself. Applies to runtime validation of profile metadata and timestamps.
- A lexical database entry may have missing or mismatched sense glosses even when its lemma and part of speech are useful. Wikidata's Italian preposition Lexeme [L1413197](https://www.wikidata.org/wiki/Lexeme:L1413197) for `attraverso` has the adverb-like gloss `trasversalmente`; verify the meaning against another source before using it as sense evidence. Applies to LexicalSense creation.
- An attested contemporary sentence is not required for every LexicalSense: the schema allows an authored example when the sense is source-backed and the sentence is checked for natural use. The `attraverso` adverb was initially deferred despite dictionary support because this distinction was missed; see the [review](runs/2026-10-25-attraverso-deferred-review.md). For an underspecified surface form, retain both direct headword readings and attested inflectional readings under their proper lemmata; see the [verb-form correction](runs/2026-10-25-attraverso-verb-form-expansion.md).
- A lexical creation result needs to identify an unresolved raw input without inventing a meaning. Use the input form and report only that it was not found in the sources checked; source unavailability is a separate outcome. Applies to unknown words in [creation.rules.md](docs/lexical_sense/creation.rules.md).
- A dictionary synonym list or translation gloss can suggest a sense without establishing that it is a current general Italian use. For contemporary LexicalSense creation, seek a direct description or contemporary usage evidence before promoting such a candidate; see the [rules update](runs/2026-10-25-contemporary-lexical-senses.md).
- When a lexical creation skill only needs to return meanings for the current input, store the Italian word or phrase directly in each sense and omit record IDs from the skill output. Any identifier needed by later persistence or exercises belongs to that later process. See the [skill output correction](runs/2026-10-25-remove-lexical-sense-output-ids.md).
- Do not assign a default output directory to an agent skill when the user has not chosen one. Return the result directly, and write files only when the caller requests a destination. Applies to [create-lexical-senses](docs/lexical_sense/create-lexical-senses/SKILL.md).
- A skill with a narrow purpose does not need a list of unrelated files it must leave untouched. State its task and source of truth; redundant prohibitions obscure the actual workflow. Applies to [create-lexical-senses](docs/lexical_sense/create-lexical-senses/SKILL.md).
- When a skill is intended to be self-contained, bundle the rules and schema it needs under `references/` and link them locally. Copied references become the skill's own version and need deliberate updates when the source documents change. Applies to [create-lexical-senses](docs/lexical_sense/create-lexical-senses/SKILL.md).
- For a skill whose batch output is consumed through OpenAI Structured Outputs, keep one API-compatible `text.format` file for the batch and check returned records against their separate record schema. A second batch schema adds maintenance without helping this workflow. Applies to [create-lexical-senses](docs/create-lexical-senses/SKILL.md).
- A skill can instruct an agent to search the web and verify pages, but the Responses API caller must enable `web_search` in `tools`; a skill file cannot grant its own tool access. Avoid hard-coding one source when the task calls for general web research. Applies to [create-lexical-senses](docs/create-lexical-senses/SKILL.md).
- Nest constructors that depend on injected classes should use explicit `@Inject(Token)` when running through tsx/esbuild; this runtime did not emit `design:paramtypes`, so Nest called `ProfileService` without its `TaxonomyService`. Cover source-mode container startup with a regression test. Applies to Nest development runtimes that transpile TypeScript without decorator metadata.
- When users select AI-generated `LexicalSense` records for persistence, keep the validated draft on the server and accept only selected indices plus permitted edits from the browser. A client-supplied full record could bypass generation and source validation. Use a database uniqueness key for deterministic retry safety, and still show existing senses for human review of semantic near-duplicates. Applies to the LexicalSense import flow.
- Prisma CLI gives an exported `DATABASE_URL` precedence over `.env`, even when it reports loading `.env`. If a SQLite schema reports that the URL must start with `file:`, check the active shell variable before changing the schema; see the [migration run](runs/2026-10-25-prisma-migrate-url-override.md).
- Keep browser code in `src/browser/*.ts` and compile it to `dist/browser/*.js`; Nest serves the output under `/assets/`. Register the `/assets/` static root before the general `public/` root, or the general HTML fallback can answer script requests. Applies to the Nest browser build and static route configuration; see the [migration run](runs/2026-10-25-browser-typescript.md).
- When paginating a list with search, filter in the database before counting and selecting a page; filtering only the loaded page hides matching records elsewhere. Refresh the current page after deletion so an emptied last page can move back. See the [pagination run](runs/2026-10-26-stored-lexical-senses-pagination.md).
