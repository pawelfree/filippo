# Lessons learned

Read this index before working on related areas. Add concise, evidence-based lessons here after a bug fix or other reusable finding. Put longer explanations in `lessons/YYYY-MM-DD-slug.md` and link them from the entry.

- When a CSS class sets `display`, add an explicit `[hidden] { display: none }` rule for views initially hidden by HTML. The taxonomy browser's grid rule would otherwise override the user-agent treatment of `hidden` before data loaded. Applies to browser interfaces with conditional sections.
- When validating JSON Schema with Ajv, install and register `ajv-formats` for schemas that rely on `date-time` or `uri`; Ajv does not enforce those format keywords by itself. Applies to runtime validation of profile metadata and timestamps.
- A lexical database entry may have missing or mismatched sense glosses even when its lemma and part of speech are useful. Wikidata's Italian preposition Lexeme [L1413197](https://www.wikidata.org/wiki/Lexeme:L1413197) for `attraverso` has the adverb-like gloss `trasversalmente`; verify the meaning against another source before using it as sense evidence. Applies to LexicalSense creation.
- An attested contemporary sentence is not required for every LexicalSense: the schema allows an authored example when the sense is source-backed and the sentence is checked for natural use. The `attraverso` adverb was initially deferred despite dictionary support because this distinction was missed; see the [review](runs/2026-10-25-attraverso-deferred-review.md). For an underspecified surface form, retain both direct headword readings and attested inflectional readings under their proper lemmata; see the [verb-form correction](runs/2026-10-25-attraverso-verb-form-expansion.md).
- A lexical creation result needs to identify an unresolved raw input without inventing a `LexicalItem` ID. Use the input form and report only that it was not found in the sources checked; source unavailability is a separate outcome. Applies to unknown words in [creation.rules.md](docs/lexical_sense/creation.rules.md).
- A dictionary synonym list or translation gloss can suggest a sense without establishing that it is a current general Italian use. For contemporary LexicalSense creation, seek a direct description or contemporary usage evidence before promoting such a candidate; see the [rules update](runs/2026-10-25-contemporary-lexical-senses.md).
